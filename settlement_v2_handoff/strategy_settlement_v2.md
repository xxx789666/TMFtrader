# 策略卡 — settlement_v2(週二籌碼變化 → 週三結算,加訊號強度濾網)/ 2026-06-09 凍結

> v2 = [[strategy_settlement_v1]] + **訊號強度濾網**:只在 `|z(d_put_oi)+z(fx_dnet)| ≥ 0.7` 時才做,弱訊號的結算日空手。**不設止損**(已證固定/移動止損都傷績效)。
> 回測(MXF 1口、cost 4pt):淨利 **+311,900**、PF **1.89**、年化 Sharpe **1.62**、**最大回撤 −31,550(v1 −106,900 的 1/3)**、**7/7 年全正**。
> **已過對抗式稽核**(無幻覺/無洩漏/無 pipeline bug/外資身份對/門檻非過擬合,MCPT p<0.001)。
> ⚠️ **2024 是反向異常年**(IC −0.05),濾網仍守住(PF 1.52);訊號 regime 敏感但 2025-2026 已回升。**edge 候選,凍結進前推,不直接上線。**

## 一句話
每個週選結算日(週三),用結算前一交易日(週二)收盤後的兩個籌碼**變化量**——當週到期 TXO 總 Put OI 的週一→週二變化(`d_put_oi`)、外資期貨淨部位當日變化(`fx_dnet`)——各做 expanding-z 後相加;**只有 |合成| ≥ 0.7(兩訊號強烈同向)才下單**,週三 08:45 開盤進、13:45 收盤出、1 口、不過夜、不設止損。約 2.6 筆/月。

## 為什麼 v2 > v1(濾網是真改善,非過擬合)
- v1 每個結算日都做(269 筆);v2 只做強訊號(169 筆,跳過 100 筆弱訊號)。
- **用 169 筆賺到比 269 筆更多的錢**;PF 1.44→1.89、Sharpe 0.97→1.62、勝率 54→61%、**最大回撤砍掉 70%**。
- **止損測試結論:固定止損(0.3–2.0%)與移動止損(0.4–1.5%)全部讓績效變差** —— 結算日盤中洗來洗去,止損被噪音掃到後價格又回去,砍掉開→收會賺的單。edge 在「開盤→收盤整段」,中途打斷只傷它(同 maxpain「碰目標就出=災難」教訓)。**故 v2 不設止損,改用進場濾網提品質。**

## 凍結配置
| 項目 | 值 |
|---|---|
| 訊號 1 | `d_put_oi` = (週二總Put OI − 週一總Put OI) ÷ 當日總Put OI;當週到期 expiry 聚合 |
| 訊號 2 | `fx_dnet` = 外資期貨淨OI(多−空)當日變化(finmind TX;外資=當日TX期貨OI最大法人,已驗100%穩定) |
| 合成強度 | `zsum = z(d_put_oi) + z(fx_dnet)`,z=expanding-window(只用過去、warmup 40) |
| **進場濾網** | **僅 `|zsum| ≥ 0.7` 才下單**;否則空手 |
| 方向 | `sign(zsum)`:>0 做多、<0 做空 |
| 進/出場 | 結算週三 08:45 開盤進、13:45 收盤出,1 口 |
| **止損** | **無**(固定/移動止損實測皆傷績效) |
| 成本 | 來回 4 點 |
| 頻率 | ~2.6 筆/月(169 筆 / 5.4 年) |

## 訊號衰退診斷(逐年 IC)— 重要
- 軌跡 **非單調衰退**,是 **「2021-22 高峰 → 2024 踩雷 → 2025-26 回升」**。
- **2024 是反向異常年**(IC −0.053、base 勝率 39%、base −30.9pt):那年「Put 牆增/外資加多→偏多」關係失靈甚至倒轉,一個人拉爛「後半段」統計。
- 兩年一組:2021-22 [IC 0.251 / 濾Sharpe 1.88] → 2023-24 [0.098 / 1.11] → **2025-26 [0.163 / 1.39,全面優於 2023-24]**。
- 結論:**訊號 regime 敏感(會遇反向年)但無結構性死亡,近兩年回升**;v2 濾網在 2024 異常年仍守住(PF 1.52)是亮點。

## 誠實保留 / 風險
1. **2024 反向年是真風險**:最壞不是「賺少」是「整年做反、勝率 39%」;要能扛 −3 萬等級壞年,別全壓。
2. **2026 僅 20 筆 + 大趨勢盤**(指數 34k→44k),方向型訊號順風,+96pt/筆有小樣本成分,別線性外推。
3. **門檻 0.7 在 2020-2026 挑的**(雖前後段高原各自成立)→ 仍須前推確認。
4. **僅 in-regime,無 pre-2020 真 OOS**;可能吃 2020+ 週選爆量市場結構紅利。
5. **資料時點**:上線前須確認 TXO 日 OI + 外資期貨淨穩定在週三 08:45 開盤前可得(期交所盤後 ~15:00 公布,理論滿足)。
