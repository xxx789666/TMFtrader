## 2. 訊號計算(精確規格)

### 2.1 時間軸
```
週二 13:45   MXF 日盤收盤
週二 ~15:00  期交所公布當日 ① TXO 各履約 OI  ② 三大法人期貨(含外資)
週二 15:00+  ← 算訊號(本節),決定週三做多/做空/不做
週三 08:45   按訊號開盤進場
週三 13:45   收盤平倉
```

### 2.2 兩個原始特徵(都用「週二 vs 前一交易日」的變化)

**特徵 A — `d_put_oi`(賣權牆變厚/變薄)**
1. 找出「**即將在本週三結算**」的 TXO expiry。週選=本週三到期那檔;若本週三同時是月選結算日(每月第 3 週三),則**週選+月選都算、OI 相加**。
2. 取這些 expiry 的**所有履約價、Put(賣權)未平倉量 OI**:
   - `PutOI_週二` = 週二收盤的總 Put OI
   - `PutOI_前日` = 前一交易日(通常週一)收盤的總 Put OI
3. `d_put_oi = (PutOI_週二 − PutOI_前日) / (PutOI_週二 + 1)`

**特徵 B — `fx_dnet`(外資期貨加多/加空)**
1. 取**外資**台指期(TX,大台)**淨未平倉口數** = 外資多方未平倉 − 外資空方未平倉。
   - 來源:期交所「三大法人-區分各商品契約-未平倉」TX 商品的**外資**列(直接取官方外資列,不需估算)。
2. `fx_dnet = 外資淨_週二 − 外資淨_前日`

> 註:研究端用 FinMind 取資料、且因法人名稱亂碼改用「OI 最大法人=外資」辨識(已驗 1577 天 100% 是外資)。**live 端建議直接取期交所官方「外資」列**,更乾淨。

### 2.3 合成 + 濾網 + 方向(expanding z-score)

維護一份**特徵歷史**(每個結算日一列 `d_put_oi, fx_dnet`,見 §5 暖身檔)。對當前結算日:

```
# 只用「過去」的歷史算 mean/std(不含當前這筆),需 ≥40 筆暖身
z_put = (d_put_oi_now − mean(d_put_oi_過去)) / std(d_put_oi_過去)
z_fx  = (fx_dnet_now  − mean(fx_dnet_過去))  / std(fx_dnet_過去)
zsum  = z_put + z_fx

if abs(zsum) >= 0.7:          # 訊號強度濾網(凍結門檻)
    方向 = 'long' if zsum > 0 else 'short'   # 週三做多/做空
else:
    不進場(空手)
```

**凍結常數**:濾網門檻 `ZTHR = 0.7`、暖身 `WARMUP = 40`。算完把當前 `(d_put_oi, fx_dnet)` append 進歷史,供下次用。

## 4. 實作步驟(建議)

1. **結算日曆**:能判斷「下一個 TXO 週選結算週三」是哪天、對應 expiry 代碼(週選 `YYYYMMWn`、月選 `YYYYMM`);若該週三是月選結算(第 3 週三),把月選 OI 一併納入。
2. **每週二盤後排程**(~15:30,確保資料已出):
   - 抓當週到期 expiry 的 Put OI(週二、前一交易日)→ 算 `d_put_oi`
   - 抓外資 TX 淨(週二、前一交易日)→ 算 `fx_dnet`
   - 讀特徵歷史 → 算 `z_put, z_fx, zsum`
   - 判定 `abs(zsum)>=0.7` → 輸出 `{方向, 是否進場, zsum, 進場日=週三}`;append 歷史
   - 抓不到任一資料 → 輸出「不進場」並告警
3. **週三盤前**:讀昨日輸出;若「進場」→ 掛 08:45 開盤單(MXF 近月,1 口,buy/sell=方向)。
4. **週三 13:45**:平倉(市價或收盤前數秒)。
5. **記錄**:每筆寫 paper tape CSV(entry/exit/方向/zsum/pnl),格式對齊 `data/backtest_history/settlement_v2_2020_2025.csv`,供前推比對。

> ⚠️ **重蹈覆轍防呆**:本實驗室有過 `force_close` 漏夜 bug 前科(盤末沒平到 → 部位過夜吃跳空)。**務必確認 13:45 真的平倉成功**,沒成交要重試/告警,絕不讓部位過夜。
