# 策略 edge 研究 — 經驗帳本(LESSONS)

> 每設計一個新版本(vN)前,**必讀整本**;每跑完 OOS 驗證,**不論成敗都回寫**。
> 目的:不重蹈覆轍、站在前 N 次失敗的肩膀上。配合 `strategy-edge-research` skill 使用。
> 標的/資料:台指期日盤 5m(MXF 小台 / TXF 大台,2020-03~2026-05,永豐 api.kbars)。
> 驗證器:`scripts/optimize_breakout_wfo.py::run_wfo`(walk-forward IS12m/OOS6m + 跨合約)。
> 體檢工具:`python scripts/digest_research.py`。

## 過關門檻(必要非充分)
一個版本要算「有 edge、值得繼續」,**OOS 必須同時**:
- 平均 OOS_PF **> 1.10**(兩合約皆然)
- 正報酬窗 **≥ 7/10**
- 跨合約同號 **≥ 7/10**
- **5-trial → 60-trial 不崩潰**(崩 = 過擬合)
- 每窗最佳參數 range **收斂**(滿天飛 = 過擬合)
未同時達標 → 視為過擬合/無 edge,記錄並換方向。

## 通用教訓(跨版本)
- **5-trial 看起來很神 = 過擬合陷阱**(v1 曾 +135萬假象,60-trial 拆穿成打平)。trials↑ OOS 必須守得住才算數。
- **參數每窗滿天飛 = 沒有穩定結構**(獨立於 PF 的過擬合鐵證)。
- **MXF/TXF 是同一台指(價差 std 2.6 點),結果該一致**;背離 = 落在噪音範圍。
- LLM(Opus）給的重設計**是假設、會錯**;OOS 過關前不准相信(含我自己的)。
- **「指數漲」不等於有 edge**;策略要的是趨勢的「乾淨度」(Kaufman ER),低 ER 震盪年必虧。

## v0 — 原始 BreakoutTrend v6b（基準）
- **結構**:Mode A 壓縮→波動擴張突破 + Mode B 趨勢回調;ADX/DI/EMA 過濾;trail 出場。
- **假設**:壓縮後突破會延續。
- **OOS 結果**(60-trial):MXF 淨 −99,089(正窗 3/10、PF 0.85);TXF −439,608(3/10、PF 0.88)。跨合約同號 9/10(都一起虧)。
- **判決:無 edge。** 全期 in-sample PF 1.567 是 2026 短樣本假象;6 年 OOS 兩合約皆負。
- **教訓**:波動突破在台指日盤長歷史沒有可外推 edge;優化越用力 OOS 越差。

## v1 — TrendPullback(砍 Mode A、只做 EMA200 對齊趨勢回調)
- **結構改動**:移除 Mode A 突破;只在「價 > EMA200(margin)+ EMA 多頭排列 + ADX 強 + DI 同向 + ema5 貼近 ema20(淺回檔)」進場(空單鏡像)。
- **假設依據**:v0 的 whipsaw 推測來自 Mode A 追擴張 → 改成「在確認趨勢中買回檔」應減少假訊號。(註:此前提**未先做虧損歸因**,是 LLM 領域知識推測。)
- **OOS 結果**(60-trial):MXF 淨 −83,537(正窗 5/10、PF 1.00、最差窗 −119,787);TXF +150,128(4/10、PF 0.99、最差窗 −399,430)。跨合約同號 9/10。5-trial 曾 +71k/+135萬(過擬合假象)。
- **判決:打平、仍無 edge。** 比 v0「沒那麼爛」(PF 0.85→1.00、正窗 3→5/10、TXF 轉正),方向(趨勢回調 > 突破)對,但幅度不足過門檻。
- **教訓**:(1) 趨勢回調確實優於波動突破,但單靠它在台指日盤 5m 推不到 edge;(2) 5-trial 假象再次出現、驗證器再次抓到;(3) **下一步該先做「v0 虧損歸因(Mode A vs B / 多空 / regime)」再設計 v2**,別再純推測。

## v2 — Kill A-short(數據歸因驅動:砍掉突破式做空)
- **依據(數據,非推測)**:`attribution_breakout.py` 拆 v0 全期 →
  A-short 桶 −100,703 / PF 0.58(單一最大失血);A-long +112k/1.47、B-long、B-short +60k/1.30 皆正;
  空單整體 PF 0.91、多單 1.39。根因:2020-26 結構性多頭裡「突破式做空」逆大勢。
- **結構改動**:原 BreakoutTrend,但**抑制 A-Squeeze SHORT 進場**(wrap on_kbar,其餘不動)。
- **OOS 結果**(60-trial,= 5-trial 完全相同→無過擬合崩潰):MXF +124,554(正窗 3/10、最差 −37,703);
  TXF +585,187(3/10、最差 −82,146)。跨合約同號 8/10。
- **判決:目前最佳,但仍不過門檻。** ✅淨翻正(v0/v1 皆負)、✅無過擬合、✅跨合約一致;
  ❌正窗僅 3/10(需 ≥7/10),獲利幾乎全擠在 2024-03 一窗 → 仍是「趨勢窗收割、塊狀報酬」。
- **教訓**:(1) **數據歸因 > LLM 腦補**:砍 A-short(數據指出)有效,勝過 v1 砍整個 A(我推測);
  (2) 移除「結構性逆勢桶」能把淨值由負轉正、且不過擬合,**但解不了「7/10 震盪窗照虧」**;
  (3) 要上 7/10 正窗,只能「震盪窗不交易」(但 ER 過濾已證會過擬合)或接受塊狀報酬縮部位;
  (4) 多空不對稱是真的(多 PF 1.39 / 空 0.91)—— 但高度疑似多頭 regime 紅利,空頭年(2022)該單獨檢視。

## 尚未嘗試的方向(候選假設池)
- **虧損歸因驅動**:先拆 v0/v1 的 OOS 虧損(模式/多空/regime),讓 v2 由數據逼出。
- **時間框架**:目前固定 5m;試 15m/30m(降噪)或 1m(更細)。
- **方向限制**:2020-2026 偏多頭 → 試「只做多」或「依 EMA200 長期方向單向」。
- **regime 閘(結構性,非事後 ER 過濾)**:用 *事前可得* 的趨勢度量(如長均線斜率)決定開不開倉。
- **完全不同訊號族**:開盤區間(ORB 日盤版)、均值回歸(僅震盪 regime)、波動率、跨期價差。
- **出場重設計**:目前 trail/early-cut;試固定 R:R、分批、ATR-chandelier。
