## 1. maxpain_put paper 規格(訊號 100% 同凍結 v2,只動執行層)

| 項目 | 規格 |
|---|---|
| 訊號 | **同 live v2**(EARLY67、dist>0 做多),**不新增任何訊號參數** |
| 期貨腿 | 同 v2:訊號日 t+1 08:45 進 **1 口小台 MXF**;+1% 加碼第 2 口 |
| **put 腿(新)** | 期貨成交後**立即**買 **1 張 TXO put**:到期=**v2 訊號所用的那個週選到期**(結算週三);履約價=**最近 ≤ 成交價×0.98 的檔** |
| 加碼時 | 第 2 口期貨成交後**立即**再買 1 張 put,履約價=最近 ≤ E2×0.98(會比第一張高一檔) |
| **停損** | **無 −2% 硬停**(put 即地板,跳空穿不過)← 與 v2 的唯一差異 |
| 出場 | 期貨腿同 v2 抱到週選結算出場;put 現金結算自動(不平倉、不停損;歸零=保險正常結局) |
| 口數比 | **MXF : put = 1 : 1**(都是 50 元/點)。⚠️ 若任何腿改用微台 TMF(10 元/點):**5 口 TMF : 1 張 put** |
| put 下單 | paper 記兩欄:**掛中價**與**吃 ask**(執行滑價=本線首要驗證目標);建議實掛=ask(立即成交,保守) |
| 帳戶 | VPS 自己的永豐金鑰(IP 白名單含 VPS)、**simulation=True、不下真單** |

**每口地板(合約保證,2026 水位 46,000 例)**:(E−K)+保費 ≈ 950 點+保費 = 最多虧 ~NT$47,500+保費/口,
**任何跳空/跌停都穿不過**。

## 4. 日誌格式(data/paper/maxpain_put/decisions.csv)

## 5. 回報事項(paper 首要要驗的,依重要序)

1. **put 實際成交成本 vs 回測 settle 假設的 gap**(回測用進場日 settle 價;真實吃 ask
   可能貴 2-10 點/張 → 若 gap 中位 >10 點/張,逐年差額表要下修重算)。
2. **−2% 檔位當週的流動性**(2% OTM 週選通常有量;若無報價/spread>15 點,記錄並改掛鄰檔)。
3. **營業員確認**:自然人帳戶「小台多單+買同週 TXO 賣權」有無組合保證金減收。
4. 25 筆後:與 v2 逐筆差額的分布是否符合回測型態(反彈週 +/陰跌週 −)。

## 6. 判活/升級標準(25 筆起評,50 筆終審;由使用者收口)

- (a) put 成交成本 gap 中位 ≤10 點/張
- (b) 差額型態符合回測(洗盤週贏/陰跌週輸,而非隨機)
- (c) 無執行問題(下單失敗/檔位缺報價/結算對不上)
- 三項過 → 報告使用者,由使用者決定是否把 put 升級為 v2 執行層標配(lockbox 外變更)。
