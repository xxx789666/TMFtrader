## 1. Spread paper 規格(零新參數,訊號 100% 同凍結 v2)

| 項目 | 規格 |
|---|---|
| 訊號 | **同 live v2**:週選 ~6DTE 算 Max Pain,`dist=(MaxPain−現價)/現價 > 0` 才做(只做多向) |
| **建倉條件** | maxpain 履約 > ATM 履約(差 ≥1 個履約間距);否則**跳過**(spread 結構性無法建倉) |
| 腿 1(買) | 買進 **ATM Call**(履約最接近現價),當週(結算週三)到期 |
| 腿 2(賣) | 賣出 **maxpain 履約 Call**,同到期 |
| 進場時點 | 同 v2:訊號日 t+1(回測用 close,live 可開盤後;**記錄實際成交價與當時買賣價差**) |
| 口數 | **1 組**(paper 階段;目標 3 組) |
| 出場 | **抱到結算,不平倉**(TXO 歐式現金結算,自動結算零滑價)。**無停損、無加碼、無止盈** |
| 最大虧損 | = 淨權利金(回測均 ~141pt ≈ 7,050/組)→ 不怕跳空,不需盤中監控 |
| 資金 | 淨權利金 + 價差保證金,估 ~30-50k/組(**請回報永豐實際保證金規則**) |

## 2. Paper tape 欄位(對齊回測口徑,供之後對帳)

`data/maxpain_spread/decisions.csv`:
`signal_t, expiry, dist, S, maxpain, K_long, K_short, prem_long, prem_short, net_prem, bidask_spread_long, bidask_spread_short, settle_index, pnl, skipped_reason`

- **每週都寫一列**(含跳過的:`skipped_reason = dist_too_small / no_signal`)。
- `settle_index` 用期交所公告最終結算價;pnl = (max(S*−K_long,0) − max(S*−K_short,0) − net_prem − 成本) × 50。
- **重點觀察項**:實際 bid/ask 價差(回測假設 2pt/腿)、賣腿是否成交、保證金實額。

## 3. 期貨 v2 paper 的 dist 濾網雙欄(順手做)

- 既有 v2/v3 paper tape 加一欄 `dist_filter_pass`(= maxpain 履約 > ATM 履約)。
- **live 進場規則不變**(凍結);只是記錄,讓未來能比「過濾 vs 不過濾」的 forward 真實差。
- 背景:in-sample 濾掉 21 筆虧 −90,646(5/6年負),**但隨機剔除對照 p=0.134 不顯著** → 觀察級,需 forward 樣本判生死。

## 4. 通過標準(何時讓 spread 轉衛星倉)

累積 **≥ 25 組**(約半年)paper 後檢查:
1. paper PF ≥ 1.2 且方向與回測一致(回測 PF 1.31);
2. 實際進場成本(價差+滑價)≤ 每腿 ~3pt(回測假設 2pt;若實測 >5pt → 載具經濟性崩,否決);
3. 保證金實額 ≤ ~60k/組;
4. 無系統性執行問題(賣腿掛不到、組合單被拒等)。
→ 全過:以 3 組(~150k)衛星倉進組合,**與期貨池資金分離**;任一不過:回拋 lab 重議。

## 5. 風險與已知保留(務必讀)

1. **熊年仍虧**(2022 回測 −43k/組級):spread 只封頂、不解熊年;衛星倉部位要按此設。
2. **dist 濾網/子集增益尚未統計顯著**(p=0.134)——別把回測 +31% 當保證,paper 才算數。
3. 賣腿是 OTM(均距 ~600pt)週選,流動性通常夠,但**價差實測是本次 paper 的核心目的之一**。
4. 回測進場用 t+1 close、live 若開盤進會有偏差 → tape 記實際值即可,不用遷就回測。
5. **資料陷阱**(供對帳):FinMind TXO 到期日 `settle` 欄被清 0,結算內含值要用最終結算指數算(回測用 put-call parity 反推)。
